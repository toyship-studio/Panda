# Physics: the editor part

What the editor shows for the module, built on PandaEditorKit: the inspector sections of the
seventeen components, the collider outlines and the joint drawings of the viewport (a viewport
overlay) and the PHYSICS section of the editor settings (Show Colliders, Show Joints). The entry point is `src/Panda/PhysicsEditor/PhysicsEditorEntry.cpp`.
Linked into the editor only.
