# Terrain: the editor part

Built on PandaEditorKit: the Terrain 2D/3D inspector sections, the asset editor tab of `.terrain`
with its dialogs, the brush tool of the viewport, the TERRAIN and FLORA settings sections, the
flora statistics, the material previews of the layered shaders. The icons are in
`resources/terrain-icons/`. The entry point is `src/Panda/TerrainEditor/TerrainEditorEntry.cpp`.
Linked into the editor only.
